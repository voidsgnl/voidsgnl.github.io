# BishopSpace

A personal portfolio and project home for **[bishopspace.me](https://bishopspace.me)**.

BishopSpace showcases software projects, creative experiments, and ideas in progress.

## Built with

- Semantic HTML
- Responsive CSS
- Vanilla JavaScript
- GitHub Pages

## Local preview

Open `index.html` in a browser, or serve the folder with any static web server.

## Updating the portfolio

- Edit the project cards in `index.html` to add, remove, or update featured work.
- Adjust colors, typography, spacing, and responsive layouts in `styles.css`.
- Keep interactions and mobile navigation in `script.js`.
- The `CNAME` file connects the GitHub Pages site to `bishopspace.me`.

## Deployment

The site is served from the `main` branch through GitHub Pages. Changes committed to `main` will be published by GitHub Pages after its deployment completes.
